# WritingRobot

基于 Rust + egui 的写字机器人 / 笔式绘图机上位机。把文字、表格、练字格、手绘和照片线稿排成一页笔迹，生成 GRBL / Marlin / EBB 固件的 G-code，并通过串口、蓝牙、TCP 或模拟器直接驱动机器。

![默认样板笔迹预览](out/preview.png)

## 核心功能

- **创作排版**：多文本框、表格、田字格 / 米字格 / 回宫格、鼠标手绘、自由笔记块；支持多模块叠加到同一页。
- **图片转线稿**：11 种绘制方式，支持裁剪、缩放、旋转、反相、扫描角度与路径排序；其中「素描原稿」会自动分辨线稿与色调稿——线稿逐笔描墨脊，照片/肖像则用线条疏密表现明暗；「分区重绘」再把素描稿按 3~8 档深度分块、逐层换笔重画；「素描笔触」进一步用短直线段、按剩余墨量决定疏密，暗部密、亮部疏，像真正的铅笔素描。
- **多笔分层（换笔绘制）**：把明暗带分给 HB/2B/4B/8B 或 0.25–1.0mm 针管笔，线宽与深浅由笔本身决定，不再逼一支笔靠密度硬撑。每支笔独立生成 G-code、逐支提示换笔，可设套准偏移；导出时同时生成合并版和分笔 `.nc` 文件。
- **大纸张分页**：图片超出单页幅面时按 200×280mm 自动切块、逐页绘制，换纸后按四角标记拼接；画布底部提供分页缩略图，可直接选择打印第几页；设备页也可单独绘制 1cm 四角 L 定位标记。
- **矢量导入**：DXF / SVG 导入为可绘制笔迹，PDF 按页导入。
- **字体**：加载 `.gfont` 笔画字库；字号、行距、字间距、对齐、段首均可调，带手写随机抖动。
- **设备连接**：有线串口 / 蓝牙串口 / TCP / 模拟器；后台自动扫描端口、自动波特率、固件查询、断线重连与保活心跳。
- **机器控制**：解锁、回零、点动、抬落笔、测试方框、自定义起止 G-code、激光模式（M3/M5）。
- **运行保障**：绘制前幅面边界检查、流控等待 `ok`、单步下发、实时进度 / 耗时 / 剩余时间。
- **输出**：G-code（`.nc`）、SVG、PDF、PNG，以及可重新打开的工程文件（`.wprj` / `.json`）。

## 图片线稿的 11 种方式

| 模式 | 效果 | 适用素材 |
| --- | --- | --- |
| 线框（边缘影线） | 沿边缘铺影线 | 线条清晰的照片、扫描稿 |
| 素描（影线） | 按明暗阈值逐行铺影线 | 通用照片、最经典的效果 |
| 高效（连续笔画） | 影线串成长笔画，抬落笔最少 | 追求速度的大面积图 |
| 中心线（骨架） | 细化成单像素骨架再描线 | 线稿、logo、硬笔字 |
| 描边（等值轮廓） | 只画明暗交界的轮廓 | 简笔画、卡通图 |
| 交叉排线（明暗） | 主方向打底，暗部叠垂直排线 | 需要层次感的素描 |
| 网点（半调） | 按灰度生成大小不一的网点 | 照片、版画风格 |
| 素描原稿 | 自动分辨「线稿 / 色调稿」：线稿逐笔描墨脊，色调稿提取原稿真实的铅笔笔触 | 铅笔素描草稿、照片肖像、手绘线稿 |
| 素描调子（分层排线） | 按明暗分层铺排线：亮部留白，暗部两组交叉线反复加深，轮廓单独提线；可开启多笔分层，由不同深浅的笔分别负责亮部/中间调/暗部 | 照片肖像、静物，想要铅笔素描感 |
| 分区重绘（深度分层） | 把调子量化成 3~8 个深度层，细块决定每片排线走向，逐层换笔、逐层交叉叠加，直到整张画完成 | 已完成的黑白素描稿、想要「按工序重画」的肖像/静物 |
| 素描笔触（融合布线） | 短直线段逐遍补墨：暗部线挨线、亮部留白，走向跟随轮廓/原稿，深色区交叉叠加；结构线最后单遍压形 | 照片肖像、静物、想要真实铅笔素描密度与笔触的素材 |

> 素描原稿怎么用：先把「画笔线宽」填成你实际用的笔（0.5 ≈ 中性笔，0.3 ≈ 针管笔）。它有两层作用——既决定两根线最近能排多密，也决定**识别的细度**：检测尺度跟着笔宽走，比笔细十倍的线本来就画不出来，找出来只会糊成一团黑。
>
> 算法不重画、只提取：用多尺度 Hessian 找出「法向弯、沿脊平」的暗脊（抹开的阴影是各向同性的，拿不到响应，所以不会被误描成线），然后**沿脊方向场做流线追踪**——从脊的局部峰值出发，顺方向场积分，把一串碎响应串成一条长弧，最后缝合断头。**位置、走向、长短都由原稿决定**，不是照明暗另排一套——早先「按明暗编一套排线」的做法会让画面变成两层互不相关的笔迹（一层跟着形体、一层是等距直梳），看着就不像原稿。
>
> 识别阈值是**局部归一化**的：脊响应先除掉邻域（约 2.2mm）的上包络。头发区的响应天生比脸颊强一个量级，用全局分位去切会被头发占满，脸上的浅笔触排不进来。墨量是**按图自校准**的：先跑一遍量「画了多少墨 / 原稿有多少墨」，偏了就按比值缩放间距重跑一遍——不同稿子能被提取出来的笔触疏密差一倍，一套常量拧不准。
>
> **物理上限**（写在前面，别再为此调参）：原稿发丝常常只有 1~2px、间隙 1~3px，头发区覆盖率能到 70~90%；而 0.3mm 的笔在 140mm 幅面上要占 2.3px，单笔能画的密度只有原稿的 1/4~1/10。糊成一片的暗部内部没有脊可提，靠提取填不满；再加密只会把脸画脏。要更还原，得从源头换：分辨率更高、笔触分得开的原稿，或者把幅面缩小、笔换细。
>
> 「识别密度」决定描到多浅的线为止：调高，鼻子、嘴角的浅结构会出来；但再高，扫描噪点和纸纹也会被当成线（脸上立刻显脏）。调低则只剩五官和重轮廓。「手抖幅度」0 是严格描摹，0.1~0.2 最像手画。线稿（白纸＋细线）会自动走另一条路：沿墨脊逐笔追踪。
>
> **素描调子（分层排线）** 是另一条路：不逐笔提取，而是把灰度当成「需要多少墨」，用线条疏密去还原。单色笔没有灰阶，灰只能来自「留出多少纸」：亮部一根不画；中间调铺一层稀排线；越暗叠越多层，但只交错**两组方向**（0° 与 +42°），层数再多也不会织成乱网。每根线的间距由它脚下一段的平均调子反算：覆盖率 = 1 − (1 − 调子)^(1/层数)，线距 = 笔宽 / 覆盖率——暗部自动压到 3.2 个笔宽，亮部自动放开到 20 个笔宽。
>
> 头发、衣褶这类「很暗且方向一致」的区域会跟着方向场走：排线沿原稿的等调子线（也就是发丝、布褶的走向），每层只偏几度，看起来是顺着发丝画的，而不是一张斜网格。连成一片的浅灰背景（照片底色、纸外背景）会从顶边泛洪找出来并当纸白处理，不再满屏「下雨」。轮廓另走一条「0.4mm 调子 − 2.2mm 调子」的细节带：眼睛、鼻翼、唇缝、领口都会稳定浮出来；断开的短段在首尾 1.2mm、方向差 37° 以内会接成一根，最强的（眼线、唇缝）叠第二遍压重，浅结构一笔带过。
>
> **分区重绘（深度分层）** 把一张素描当成施工图：先量出每个像素的调子，按有效调子的 p98 归一化后量化成 3~8 层（默认 5 层），每一层就是一整遍绘制。方向不再全图一套：每 2.5mm 见方的小块各自从墨脊、结构线、基准角里挑走向，鼻梁和眼窝挨着也能各走各的。第 k 层固定交给第 k×笔数/层数 支笔，浅层 HB 先铺灰，深层逐步换 4B/8B 压黑；每层只画落在这一档的像素，并叠加自己的交叉角（0°/+42° 交替），深色层才是真的交叉网。最深一层优先描墨脊中线而不是等值轮廓——轮廓会把原稿每根线的两侧各描一遍，排线稿立刻变成双线；结构段还受「排线总长 45%」的墨量预算约束，避免轮廓盖过调子。块只决定方向、不决定层，所以块可以调得很细而不会把画面切碎。
>
> **素描笔触（融合布线）** 是最接近手绘工序的一档，也是暗部细节最多的一档。它不按固定网格铺线：先把调子归一化成「每个像素还差多少墨」，每画完一遍用 0.7mm 模糊量一次当前墨量，只在缺口处落笔；线距由「笔宽 ÷ 局部覆盖率」反算，单遍覆盖上限按调子分档 86%~94%，于是暗部自动压到笔挨笔、亮部自动放开到很远——疏密是算出来的，不是全图统一间距。墨量按「最黑的一笔」记账而不是 α 叠加，多遍交叉会真的层层加深。每一笔都是 1~8mm 的**短直线段**（默认 3.2mm），长落笔再按 0.35~0.9mm 切成短弦、两端各留 12% 空档，候选点抖动并打乱顺序，落笔后用「胶囊」占位；绘制时只加亚毫米级手抖和两端收锋，不会出现跨半张脸的抽象曲线。走向有三档：跟随轮廓（等调子线/结构方向）、跟随原稿（墨脊方向）、混合（默认）；浅色调优先 2.5mm 等照线、深色区再偏 0~38° 交叉。多笔分层按覆盖率分带（HB 到 34%、2B 52%、4B 70%、8B 收黑场），四支笔都有活干。最后单独一趟结构层（细节减大调子得到的轮廓：眼线、唇缝、发丝根），按「长度封顶 60mm × 墨色²」保留最重要的一段，总量不超过笔触总长的 12%，且只描一遍——否则 1mm 的笔会把轮廓涂成 2mm 黑带。
>
> 明暗完全靠疏密表现：暗处排得密、亮处留得疏。笔只有一种墨色，不能靠「描得重」——那只会沿同一轨迹反复摩擦。
> 四角定位：**机器原点 (0,0) 就是纸面的左下角**，定位框贴在那一侧。原点那一角的 L 臂长加倍并多一道 45° 斜线，画完一眼就能确认方向对不对。若「项目与输出 → 坐标系与幅面」里显示的「0,0 实际落在纸面…」不是左下，点一下「设为左下原点」——那个读数已经把「原点角」和「反转 X/Y」的叠加算进去了，别看单项。
> 顶上那一栏的「笔 mm」是**预览用的真实笔尖粗细**（不改 G-code）：0.5mm 的笔在纸上就是 0.5mm，预览按同样比例画，屏幕和纸上看到的一样重。不填对，预览会把粗笔看成细笔，误以为排线太稀。
> 想验证还原度：`cargo test -p wrobot-gui dump_sketch_preview -- --ignored --nocapture` 会把 `tools/sketch_input.png` 重画成 `tools/sketch_verify.png`（左右对照）并打印召回率、落笔压墨率、直线度、方向差，以及**明暗比**（输出墨量 / 原稿墨量，按亮/中/暗三档分别统计）与调子相关 r。`SKETCH_IN=input.png` 换输入图，`SKETCH_ONLY=edge|hatch` 只画结构线/只画排线，`SKETCH_MODE=field|ftone` 看方向场和内部调子图。
>
> 性能：中心线 / 描边 / 素描原稿对大图会先降到长边 1600px（骨架细化是迭代算法，也避免界面卡死）；网点模式最多生成约 8000 个点。素描原稿的色调稿（笔触提取）通路在 1728×2304 上约 0.27 秒，线稿通路稍慢。
>
> 视角操作：Ctrl + 滚轮缩放画布视图（以光标为锚点），普通滚轮缩放当前选中的图片或文本框。

## 多笔分层（换笔绘制）

笔的粗细和深浅首先是物理属性：0.25mm 针管笔适合浅灰细节，1.0mm 8B 才压得住黑场。与其让一支笔靠密度硬撑整个灰阶，不如把明暗分给几支真实的笔。

1. 图片页选「素描调子（分层排线）」「分区重绘（深度分层）」或「素描笔触（融合布线）」，勾选「多笔分层」。
2. 在「多笔分层 · 笔组」里选铅笔组或针管笔组，按亮 → 暗排列。每支笔可改线宽（0.15~1.6mm）、满覆盖深度、颜色和启用状态，最多 4 支；文字、边框、四角标记由「主笔」画。
3. 画布预览按每支笔的真实颜色和线宽显示。明暗带边界按各笔的深度累计分配：HB 只铺浅灰到中灰，8B 负责最后的黑场，轮廓由最深那支笔出线。
4. 点「开始绘制」后逐支提示换笔：确认机器停稳、装入对应笔，再点「开始这支笔」。每支笔的 G-code 独立以当前位置为零点（开头 `G92 X0 Y0`、结尾 `G0 X0 Y0`），换笔不会累积坐标漂移；上一支没停稳不会提示下一支。
5. 换笔后落点有系统性偏差时，填该笔的 X/Y 套准偏移（±5mm），这一层整体平移；分页裁剪前会先补偏移，贴边笔迹不会被裁掉。
6. 导出 G-code 会同时写合并版和 `xxx-pen1-HB_0_20.nc` 这类分笔文件；也可以只跑分笔文件，逐支换笔。

> 笔组里的「深度」是这支笔满覆盖时能压出的最暗值，不是装饰参数：它决定明暗带的分界。换真实笔种后按手感微调；深度填得过高，浅笔会侵占深笔的暗部。
>
> 验证多笔效果：`SKETCH_MULTI=1 SKETCH_DRAW=8 cargo test -p wrobot-gui dump_sketch_preview -- --ignored --nocapture`，会打印每支笔的笔迹数/墨量，并把分笔着色结果写到 `tools/sketch_multi_verify.png`。
>
> 验证分区重绘：把 `SKETCH_DRAW` 换成 `9`，可用 `SKETCH_LEVELS=5`（深度层数）、`SKETCH_BLOCK=2.5`（分块毫米）单独调参；同样输出每支笔的笔迹数与预览图。
>
> 验证素描笔触：把 `SKETCH_DRAW` 换成 `10`，可用 `SKETCH_LEN=3.2`（笔触长度 mm）、`SKETCH_FOLLOW=0|1|2`（跟随轮廓/原稿/混合）、`SKETCH_LEVELS=3`（遍数）单独调参；输出每支笔的笔迹数、墨量、明暗比与预览图。

## 快速开始

### 使用发布版

1. 解压 `out/WritingRobot-v0.21.0-win64.zip`（或直接运行 `out/` 里的 exe），启动 `wrobot-gui.exe`。
2. 把 `.gfont` 字库放进下列任一目录（启动时自动扫描）：
   - 程序目录下的 `gcodeFonts/`
   - `../奎享雕刻/gcodeFonts/`
   - `D:\WritingRobot\奎享雕刻\gcodeFonts`
   - `D:\WritingRobot\wrobot\gcodeFonts`
3. 打开「设备与调试」→ 扫描串口 → 选择端口 → 连接；没有机器时连接方式选「模拟」。
4. 在「创作 / 图形」里编辑内容，用左侧导航顶部的「输出图层」决定哪些模块写入 G-code（默认只输出当前页，可勾选叠加）。
5. 点「开始绘制」，程序会先检查幅面边界，再下发 G-code。
6. 画超过单页幅面的大图：在「图片」页勾选「启用分页」，画布底部会显示每页缩略图（可横向滚动），用底部页码下拉框选择要画第几页；每页画完自动回原点，换纸后继续，最后按四角 1cm L 标记对齐拼接。

### 从源码构建

需要 Rust 工具链（stable）与 Windows 10/11。嵌入 exe 图标和版本信息需要 Windows SDK 的 `rc.exe`（安装 Visual Studio Build Tools 时勾选「Windows SDK」即可）。

```bash
# 开发运行
cargo run -p wrobot-gui

# 发布构建
cargo build --release

# 运行测试
cargo test --workspace
```

产物位置：

- `target/release/wrobot-gui.exe`：图形界面（无控制台窗口，已嵌入图标与版本信息）
- `target/release/wrobot-cli.exe`：命令行工具

发布构建脚本会把 `crates/wrobot-gui/resources.rc` 中的图标与 VERSIONINFO 编译进 exe；修改 `assets/icon.ico` 或版本号后重新构建即可。

GUI 启动参数：

```bash
wrobot-gui --port COM3 --baud 115200   # 启动即连接指定端口
wrobot-gui --auto                      # 启动自动搜索并连接
```

```text
wrobot-cli probe [端口] [--baud 115200]
```

- `ports`：列出本机串口，并区分【蓝牙】与【串口线】。
- `probe`：不指定端口时扫描 `COM1..COM32`，根据固件横幅或 `$I` / `M115` 响应判断是否有写字机固件。
- `wiretest`：有线串口逐层体检；`--loop` 需先短接该口 TX/RX。
- `dxf` / `svgi`：导入矢量文件并直接生成 G-code 或 SVG。

## 工程与输出

- 工程保存为 `.wprj` 或 `.json`，记录各模块内容、图片参数、设备与固件设置。
- 导出格式：G-code（`.nc`）、SVG、PDF、PNG。
- 固件：GRBL（Z 轴抬落笔）、Marlin（Z 轴或舵机）、EBB（`SP` / `SM` 指令）。
- 页面网格默认关闭；勾选「网格」后显示可调列/行（默认 10×14）的浅色虚线网格，仅作定位参考，不会写入 G-code。
